A simple, fast, and responsive web application designed for generating, customizing, and printing **logistic storage tags for ceramic tile pallets**.

---

## ✨ Features

- 🖨️ **A4 Landscape Layout:** Specifically formatted for printing on A4 paper in horizontal/landscape mode.
- ⚡ **Real-Time Live Preview:** As you fill out the form fields, the tag preview updates instantly.
- 🎨 **Header Color Switcher:** Dynamic quick-select buttons to switch the primary header color between:
  - Slate Dark (`#1E293B`)
  - Neutral Gray (`#808080`)
  - Terracotta / Ceramic Orange (`#D1631D`)
- 🧹 **Form Reset:** Dedicated button to quickly clear all input fields for creating a new tag from scratch.
- 📱 **Dynamic QR Code:** Direct link pointing to the project repository.
- 📦 **Logistics Symbols:** Standard icons for maximum stacking, fragile handling, water protection, and upright positioning.

Aplicação web simples, rápida e responsiva desenvolvida para geração, customização e impressão de **etiquetas logísticas de armazenamento de pallets** de pisos e revestimentos cerâmicos.

---

## ✨ Funcionalidades

- 🖨️ **Layout A4 Paisagem:** Formatado sob medida para impressão em folha A4 no modo horizontal/paisagem.
- ⚡ **Atualização em Tempo Real:** Conforme os dados são preenchidos no formulário, a pré-visualização da placa atualiza instantaneamente.
- 🎨 **Troca de Cor do Cabeçalho:** Mini botões seletores disponíveis para trocar dinamicamente a cor da placa entre:
  - Azul Escuro (`#1E293B`)
  - Cinza Neutro (`#808080`)
  - Laranja Cerâmico (`#D1631D`)
- 🧹 **Limpeza de Campos:** Botão dedicado para redefinir rapidamente todos os campos do formulário para gerar uma nova etiqueta.
- 📱 **QR Code Dinâmico:** Aponta diretamente para o repositório do projeto.
- 📦 **Símbolos Logísticos:** Ícones padrões para identificação de empilhamento máximo, produto frágil, proteção contra água e sentido de transporte.
